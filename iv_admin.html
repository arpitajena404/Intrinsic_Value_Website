Export Configuration & Static Compilation

Steps to apply these changes to the live website:

  1. Verify your edits across all tabs, then click the **Generate Config** button.
  2. Copy or download the respective JSON payloads.
  3. Save the Homepage JSON to homepage_config.json and run: node scripts/update_homepage.js
  4. Save the Pricing JSON to pricing.json and run: node scripts/update_pricing.js
  5. Save the Live Funnel JS to invest_biz/live_config.js. (No build script is required for live funnel pages; they load values dynamically at runtime).
  6. Refresh the website pages to verify that everything works!
